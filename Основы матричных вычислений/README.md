Удаление фона на видео с помощью SVD. Видео записывается матрицей "пиксели x кадры". Фон - низкоранговое приближение, движущиеся объекты - разность кадра и фона.

- Усечённое SVD (ранг 1) для статичного фона
- Рандомизированное SVD и зависимость ошибки от oversampling
- Ранг 2 для видео с меняющимся освещением
- Проекция новых кадров на уже посчитанный фон
- Robust PCA: фон и разреженные объекты
