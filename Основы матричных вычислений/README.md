Удаление фона на видео с помощью SVD. Видео записывается матрицей "пиксели x кадры". Фон - низкоранговое приближение, движущиеся объекты - разность кадра и фона.

- Усечённое SVD (ранг 1) для статичного фона
- Рандомизированное SVD и зависимость ошибки от oversampling
- Ранг 2 для видео с меняющимся освещением
- Проекция новых кадров на уже посчитанный фон
- Robust PCA: фон и разреженные объекты

2. [Salman_Iasmina_PDZ-2_6_Ekonom.ipynb](https://github.com/jassalm/Resume-Projects/blob/main/Основы%20матричных%20вычислений/Salman_Iasmina_PDZ-2_6_Ekonom.ipynb)

Рекомендательная модель на ALS. Оценки MovieLens 10M хранятся разреженной матрицей "пользователь x фильм": рейтинг ≥ 4 считается положительным. Матрица слишком большая для обычного SVD, поэтому низкоранговое приближение считается методом ALS.
- Функционал ошибки через след, без сборки плотной матрицы
- ALS с ортогонализацией и расстояние между подпространствами
- Сравнение с разреженным SVD и рандомизированным SVD
- Рекомендации новым пользователям и hit rate для top-n
- Бонус: разложение Таккера и higher-order SVD
